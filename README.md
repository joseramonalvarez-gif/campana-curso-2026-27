# Entrega del sistema comercial — Proeduco

Sitio de entrega de los documentos de la campaña de curso escolar 2026/27.

**No se edita aquí.** Los documentos fuente viven en el hub de conocimiento, en
`DG-2026-01_embudos-curso-escolar-proeduco/entregables/`. Este repositorio es
solo la copia publicada: se regenera entera con el script
`publicacion/construir_sitio.py` del proyecto.

Para actualizar: se cambia el documento en el hub, se ejecuta el script y se
sube el resultado. La dirección pública no cambia nunca.

Las páginas llevan `noindex` y el `robots.txt` bloquea el rastreo completo, así
que no aparecen en buscadores. Aun así **cualquiera con la dirección puede
leerlas**: no es un sitio con contraseña.
